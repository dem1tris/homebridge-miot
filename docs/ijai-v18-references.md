[Apache-2.0 license](https://github.com/maksp86/Python-package-vacuum-map-parser-ijai/blob/53f79201b226908221379f08ec5ec568b8ed4a83/LICENSE).
- `xiaomi-vac`: [IJAI properties](https://github.com/letitbe-dull/xiaomi-vac/blob/d1eb941ac8a1c4991221a56b9ca0e380362584b4/custom_components/xiaomi_vac/spec/profiles/ijai.py#L853) and [room command arguments](https://github.com/letitbe-dull/xiaomi-vac/blob/d1eb941ac8a1c4991221a56b9ca0e380362584b4/custom_components/xiaomi_vac/vacuum.py#L215). - `hass-xiaomi-miot`: [local action transport](https://github.com/al-one/hass-xiaomi-miot/blob/8ac4df7005aefb6a92ae5f66f53fa56e2e548c16/custom_components/xiaomi_miot/core/device.py#L1300) and [named input serialization](https://github.com/al-one/hass-xiaomi-miot/blob/8ac4df7005aefb6a92ae5f66f53fa56e2e548c16/custom_components/xiaomi_miot/core/miot_spec.py#L1131). The [MIOT v18 specification](https://miot-spec.org/miot-spec-v2/instance?type=urn:miot-spec-v2:device:vacuum:0000A006:ijai-v18:1) defines the action inputs.
