# IJAI v18 protocol references

The IJAI v18 decoder reads the embedded map ID, upload time, and room IDs and names. It implements the documented format with Node.js crypto, zlib, and a handwritten Protocol Buffers reader.

- The `vacuum-map-parser-ijai` project describes the map envelope, including the AES key derivation, decryption, and zlib payload. Its `RobotMap.proto` gives the field numbers used for map metadata and rooms. This project is distributed under Apache-2.0. [Decryption source](https://github.com/maksp86/Python-package-vacuum-map-parser-ijai/blob/53f79201b226908221379f08ec5ec568b8ed4a83/src/vacuum_map_parser_ijai/aes_decryptor.py), [map parser](https://github.com/maksp86/Python-package-vacuum-map-parser-ijai/blob/53f79201b226908221379f08ec5ec568b8ed4a83/src/vacuum_map_parser_ijai/map_data_parser.py), [map schema](https://github.com/maksp86/Python-package-vacuum-map-parser-ijai/blob/53f79201b226908221379f08ec5ec568b8ed4a83/src/vacuum_map_parser_ijai/RobotMap.proto), [license](https://github.com/maksp86/Python-package-vacuum-map-parser-ijai/blob/53f79201b226908221379f08ec5ec568b8ed4a83/LICENSE)
- The `xiaomi-vac` integration documents the active map property, the IJAI room command and its argument order, and the use of the Xiaomi cloud route for room cleaning. The integration is distributed under the MIT License, copyright (c) 2026 letitbe-dull. [IJAI profile](https://github.com/letitbe-dull/xiaomi-vac/blob/d1eb941ac8a1c4991221a56b9ca0e380362584b4/custom_components/xiaomi_vac/spec/profiles/ijai.py#L853), [room command source](https://github.com/letitbe-dull/xiaomi-vac/blob/d1eb941ac8a1c4991221a56b9ca0e380362584b4/custom_components/xiaomi_vac/vacuum.py#L215), [license](https://github.com/letitbe-dull/xiaomi-vac/blob/d1eb941ac8a1c4991221a56b9ca0e380362584b4/LICENSE)
- A Xiaomi Cloud Map Extractor report documents maps from the same v18 firmware that use either the cloud device ID or `0` in the map key. [Map Extractor issue #696](https://github.com/PiotrMachowski/Home-Assistant-custom-components-Xiaomi-Cloud-Map-Extractor/issues/696)
